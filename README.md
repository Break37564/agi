# Text RPG Game

簡単なテキストベースのRPGゲームです。プレイヤーは村を出発し、森や湖、遺跡を探索しながら敵と戦います。

## プレイ方法（PC端末向け）

このゲームはターミナル／コマンドラインで遊ぶPC向けのテキストアドベンチャーです。ブラウザやスマートフォンには最適化されていません。

1. Python 3.10 以上が入ったPCで、リポジトリのルートに移動します。
2. （任意）`python -m venv .venv && source .venv/bin/activate` で仮想環境を用意します。
3. 依存パッケージは標準ライブラリのみなので追加インストールは不要です。
4. 以下のコマンドでゲームを起動します。

```bash
python -m rpg_game.cli
```

ゲーム開始後、ターミナル上でコマンドを入力して冒険を進めます。主なコマンド:

- `north` / `south` / `east` / `west`: 移動
- `take`: アイテムを拾う
- `status`: ステータスを確認
- `help`: コマンド一覧表示
- `quit`: ゲーム終了

戦闘中は `attack`, `skill`, `potion`, `run` を選択できます。

## テスト

pytest
